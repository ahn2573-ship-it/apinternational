# 에이피인터내셔널 광고 대시보드

에이피인터내셔널 브랜드(아이슨 · 프리히 · 매트스토어)의 네이버 광고 성과를 한 화면에서 보는 대시보드입니다.
에브리해빗 대시보드와 같은 구조(GitHub Pages + Supabase)에 **브랜드 구분**을 더했습니다.

- 상단 왼쪽 **브랜드 탭**(전체 / 아이슨 / 프리히 / 매트스토어), 오른쪽 **매체 탭**(전체 / SA / GFA)
- **GFA 업로드**: 브랜드마다 업로드 칸이 따로 있음 → 올린 칸의 브랜드로 저장
- **SA**: 지금은 "연동 예정". 브랜드에 Customer ID 를 넣으면 그 브랜드의 SA 탭이 열림
- 설치 방법: [`SETUP_GUIDE.md`](./SETUP_GUIDE.md)
